Kadane 算法是一种用来解决 “最大子数组和” 问题的线性时间算法。

问题是：给定一个整数数组，找出一个连续子数组，使得它的元素和最大，返回这个最大和。

例如：

text

数组：[-2, 1, -3, 4, -1, 2, 1, -5, 4]
最大子数组：[4, -1, 2, 1]
最大和：6

核心思想

Kadane 算法基于动态规划。

定义：

text

dp[i] = 以第 i 个元素结尾的最大子数组和

状态转移：

text

dp[i] = max(nums[i], dp[i-1] + nums[i])

意思是：

  • 要么从当前元素重新开始一个子数组；

  • 要么把当前元素接到前面的子数组后面。

最终答案是所有 dp[i] 中的最大值。

由于只需要前一个状态，所以可以优化成两个变量：

text

current = max(nums[i], current + nums[i])
best = max(best, current)

代码示例

python

def kadane(nums):
    current = nums[0]
    best = nums[0]
    for x in nums[1:]:
        current = max(x, current + x)
        best = max(best, current)
    return best

如果允许空子数组，可以这样写：

python

def kadane_allow_empty(nums):
    current = 0
    best = 0
    for x in nums:
        current = max(0, current + x)
        best = max(best, current)
    return best

复杂度

  • 时间复杂度：O(n)

  • 空间复杂度：O(1)

直观理解

遍历数组时，维护一个“以当前元素结尾的最大和”。

如果前面的累加和已经变成负数，那么它对后面的元素没有帮助，不如直接从当前元素重新开始。

例如：

text

current = -5
下一个元素是 3

那么：

text

current + 3 = -2

不如直接从 3 开始，所以选择：

text

current = 3

注意事项

  1. 如果数组全是负数：

    • 要求非空子数组时，答案是最大的那个负数；

    • 允许空子数组时，答案是 0。

  2. 可以扩展记录子数组起止位置：

    • 当选择从当前元素重新开始时，更新起点；

    • 当 best 被更新时，记录当前起点和终点。

  3. 二维扩展：

    • 求最大子矩阵和时，可以固定上下边界，把列压缩成一维数组，再对压缩数组跑 Kadane 算法。

一句话总结：

Kadane 算法通过动态规划思想，在 O(n) 时间内求出数组中连续子数组的最大和。
