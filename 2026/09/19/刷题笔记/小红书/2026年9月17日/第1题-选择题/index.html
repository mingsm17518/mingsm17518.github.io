第1题-选择题

本文最后更新于 2026-09-19T17:22:17+08:00

题目

1、园区门禁闸机要把多路套接字日志收进同一采集线程。IO 多路复用允许在单个线程中同时监视和处理多个 I/O 操作，以下不属于 IO 多路复用的技术是（）

  • A. poll 用描述符数组等待多个套接字就绪
  • B. eselect IO多路复用
  • C. epoll 用内核事件表减少每次等待的用户态拷贝
  • D. select 在用户态传入描述符集合并阻塞等待就绪

2、仓储货位号按插入顺序建立二叉排序树，插入序列为 (11, 13, 16, 18, 20, 22, 25)。建立好的二叉排序树是一棵（）

  • A. 所有内部结点都有两个孩子的完美树
  • B. 按层从左到右填满的堆序树
  • C. 右向单支树
  • D. 每个结点只保留左孩子的递减链

3、单核质检台配有读码枪和喷码机各 1 台。现有 4 份并发工单，每份的采集、核算和喷码时间分别为 2ms、3ms 和 4ms，且都按采集、核算、喷码的顺序执行。执行完这 4 份工单需要的时间最少是（）

  • A. 13ms
  • B. 9ms
  • C. 17ms
  • D. 21ms

4、实验台账库要做夜间备份，运维选用 mysqldump。下列关于 mysqldump 的说法，正确的是（）

  • A. 通过生成 SQL 语句实现数据库的逻辑备份
  • B. 通过停库后打包数据文件实现冷物理备份
  • C. 通过二进制日志实时回放实现热同步
  • D. 通过存储引擎页拷贝做增量物理备份

5、变电站检修班组人事库中，表结构如下：①检修员表(工号, 姓名, 性别, 出生日期, 入职日期, 班组编号)；②出勤表(工号, 年份, 月份, 出勤量)。若完成操作：显示所有姓「王」和「赵」的检修员信息。以下操作可行的是（）

  • A. select * from 检修员表 where 姓名='王%' or 姓名='赵%'
  • B. select * from 检修员表 group by 工号 having 姓名 like '王' or 姓名 like '赵'
  • C. select * from 检修员表 where 姓名 like '[王,赵]%'
  • D. select * from 检修员表 where substring(姓名, 2, 1) in ('王', '赵') ## 参考答案与解析

1. B。poll（描述符数组）、epoll（内核事件表 + 回调，避免每次拷贝整个集合）、select（fd_set 集合）都是经典 IO 多路复用；「eselect」并非真实存在的多路复用机制（回忆稿或有笔误），按「不属于」只能选 B。

2. C。严格递增序列插入 BST，每个新数都大于当前所有结点，一路成为右孩子，最终形成只有右链的单支树。

3. D（21ms）。三道工序构成流水线：首份工单走完全部工序需 2+3+4=9ms；之后每份只需等待瓶颈工序（喷码 4ms），即 9 + 3×4 = 21ms。流水线公式：∑ti+(n−1)⋅max⁡ti\sum t_i + (n-1) \cdot \max t_i。

4. A。mysqldump 的原理是把库表内容导出为一连串 CREATE TABLE / INSERT 等 SQL 语句，恢复时重新执行这些语句，属于逻辑备份；B 是冷物理备份（如 xtrabackup 关闭实例后拷贝数据目录的做法），C 是 binlog 主从复制/实时同步，D 是物理增量备份，均与 mysqldump 无关。

5. 正确写法应为 where 姓名 like '王%' or 姓名 like '赵%'（或 left(姓名, 1) in ('王', '赵')）。逐项看：A 用 = 匹配通配符字符串，等值比较无法匹配「王某某」（若原题确为 like 则 A 正确）；B 的 like '王' 只匹配单个字，且 group by 用法不对；C 的 [...] 字符类不是 MySQL LIKE 语法（SQL Server 才支持 [王赵]）；D 取的是第 2 个字符，姓氏应从第 1 位开始（若原题为 substring(姓名, 1, 1) 则 D 正确）。按回忆稿字面所有选项均有瑕疵，考试时以「最接近正确语义」判断。
